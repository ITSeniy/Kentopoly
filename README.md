# Kentopoly

A browser-based 3D economic board game for 2–6 players with local and server-backed sessions.

## Technology

JavaScript / TypeScript

## Repository layout

Primary areas: `public/`, `tests/`.

## Build and verification

```bash
npm install
npm run build
npm test
```

Exact requirements may vary by platform. Check project-specific documentation and configuration before building.
