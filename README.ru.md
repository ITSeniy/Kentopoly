# Kentopoly Table · alpha 0.3

Браузерная экономическая настолка для 2–6 друзей. Один полноэкранный 3D-стол, без отдельной оболочки сайта и без резервного 2D-поля. Игровая экономика v0.2, раскладка и настройка игроков v4. Все деньги вымышленные.

## Быстро попробовать

Откройте `Kentopoly-Table-demo.html` в актуальном браузере с WebGL. Интернет и установка пакетов для этого файла не нужны. Выберите 2–6 участников — люди по очереди играют на одном экране, это не боты и не сетевой режим. Сохранение хранится локально; его доступность зависит от браузера и режима открытия файла.

Для удобного управления откройте HTML отдельной вкладкой или окном. В маленьком предпросмотре Notion рабочая область ограничена размером встраивания.

## Что изменилось

- Весь интерфейс расположен поверх единой 3D-сцены: участники, действия, выбор клетки, меню и камера. Старое 2D-поле удалено из интерфейса и логики отображения.
- На стартовом экране стол медленно вращается под лёгким размытием. Перед партией каждый игрок отдельно выбирает банк и одну из шести фигурок; после готовности всех участников игра запускается автоматически.
- Хроника — обычный текст внутри поля, без карточки и всплывающего журнала. «Ранее» и «Сейчас» перелистывают события на месте. На телефоне одновременно видно меньше строк.
- **20 — 2026 Awards, 30 — Поиск.** Карта Chance тоже ведёт на новый Поиск.
- Яркие цвета групп, изумрудное поле, синие края, золотые свитки, стопки вымышленных денег и монеты. Это оригинальная программная 3D-графика.
- Обычные клетки вытянуты как карточки, угловые остаются квадратными. Подписи статично ориентированы под камеру по умолчанию и больше не поворачиваются вслед за ней.
- Постройки стоят на внутреннем краю клетки, окрашиваются в цвет владельца и отличаются по сектору: жилые дома, торговые здания, сервисные центры и корпоративные башни. Фишки движутся по свободному внешнему краю.
- За полем сохранена крупная стопка денег; остальные декорации заменены на более многочисленные и удалённые стопки жетонов и колоды карт.
- Камера сопровождает фишки; ручной поворот, обзор и масштаб сохранены.
- Бросок разыгрывается двумя объёмными кубиками на столе: сначала видны выпавшие грани, затем сумма, и только после этого начинает двигаться фишка.

## Управление

- Перетаскивание — поворот камеры; колесо и кнопки +/− — масштаб.
- «Обзор» возвращает общую композицию; «Следить» включает сопровождение. Ручной поворот отключает его.
- Нажмите клетку или выберите её в нижнем списке, чтобы открыть описание. Длинные названия и точные суммы находятся в инспекторе.
- «Меню»: портфель, правила и выход. На телефоне карточки игроков пролистываются горизонтально, длинные панели действий — вертикально.
- При уменьшении движения в настройках системы перемещения показываются без автоматической анимации.
- При недоступном WebGL появляется сообщение и повторный запуск. Автоматического перехода в 2D нет.

## Сетевая партия

Нужен Node.js 22+; тестирование выполнено на Node 24. Внешних runtime-зависимостей нет.

```sh
cd kentopoly-table
npm start
```

Откройте `http://localhost:8787`, создайте комнату и отправьте приглашение друзьям. В одной локальной сети используйте LAN-адрес компьютера с сервером вместо localhost; сервер и брандмауэр должны разрешать подключения. Компьютер должен оставаться включённым. Можно использовать `start-windows.bat` или Dockerfile из архива.

Для разных сетей требуется отдельно размещённый сервер с HTTPS. Публичный адрес в этой поставке **не создан**. Не открывайте незашифрованный порт в интернет. Настройте reverse proxy с сохранением Host, отключённой буферизацией SSE и длинным тайм-аутом; включите `COOKIE_SECURE=1`.

Переменные: `PORT=8787`, `HOST=0.0.0.0`, `DATA_DIR=saves`, `COOKIE_SECURE=0` для локального HTTP / `1` для HTTPS.

## Сохранения

Снимки alpha 0.1/0.2 автоматически получают новую раскладку. Фишки на старых специальных углах остаются на соответствующей функции: 20↔30. Перенос не даёт зарплату и не меняет деньги, бренды, собственников, уровни, кубок или кредит. Старая история анимации сбрасывается, журнал сохраняется.

Перед обновлением сервера сделайте копию `saves`. Не открывайте обновлённую партию старым клиентом. Сохранения содержат приватные сведения и не входят в архив поставки.

## Сохранённые механики

Старт $1 млн и $150 тыс. за обычное прохождение; 40 клеток, 90 кандидатов брендов; покупки, комиссии, три уровня, цветовые пары; фонтаны по $200 тыс. с автоусилением; единственный переходящий Awards ×2; Поиск, Тюрьма, Chance/Risk; аукционы, сделки, принудительный выкуп; спасение, добровольный кредит ЦБ и ручная ликвидация; победа за четыре фонтана, четыре монополии или банкротство остальных.

## Код и проверки

```sh
npm test
npm run build:demo
```

- `public/engine.mjs` — правила и миграция; `data.mjs` — контент.
- `public/scene.mjs` — собственный WebGL-рендерер, модели, камера и выбор клетки.
- `public/app.mjs`, `style.css` — интерфейс и диалоги.
- `server.mjs` — HTTP/SSE, сессии, команды, таймеры и JSON-снимки.
- `tests/` — 38 автоматических тестов; детали в TEST-RESULTS.md.

Хроника технически реализована прозрачным DOM-текстом с привязкой к проекции внутренней области поля. Это не отдельная панель и не текстовая WebGL-модель.

## Ограничения альфы

Это не завершённый MVP. Нет публичного хостинга, живой балансировки, официального комплекта логотипов и полного аудита безопасности, доступности или всех браузеров/GPU. Декоративные банковские метки не являются формой входа в банк; реальные финансовые данные не запрашиваются.

Архитектура — JavaScript ES modules + Node HTTP/SSE, не целевые React/TypeScript/Socket.IO/PostgreSQL. JSON-снимки через rename — не транзакционная БД и не гарантия при потере питания. Один процесс на папку saves. Не реализованы миграция хозяина, удаление гостей/отзыв приглашений, короткие коды, подтверждение хозяином, межустройственное восстановление и эксклюзивный управляющий клиент. Серверные таймеры проверяются с интервалом; пограничные гонки требуют дальнейшего усиления. В журнале до 180 событий. Нет обещания FPS на любом телефоне.

HTTP-тест шести участников — программные клиенты, а не плейтест шести человек. Для закрытой игры с друзьями сначала проверьте выбранные устройства и сеть.
